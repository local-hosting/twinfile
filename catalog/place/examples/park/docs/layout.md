# Central Park — layout map

**`open_area`** site: outdoor program only (`meadow`, `trailhead`). No building `copy:` — there is no indoor twin to nest.

For shelter scenarios on open land, bind **`roles: outdoor`** on spaces and use situations that do not require indoor shelter, or add an optional visitor-center as another `spaces:` step (see [`port`](../port/) warehouse row) or a nested `copy:` when the stack is large ([`arena`](../arena/)).
