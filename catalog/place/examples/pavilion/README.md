# Example pavilion

Vendor-neutral **place** (`twinfile/place/pavilion:0.1.0`) on `base-single-level`: foyer + gallery hall with shelter roles. Extend for country or thematic pavilions (`from: twinfile/place/pavilion:0.1.0`).

`geotype.primary: museum` is the closest registry pin until a dedicated pavilion/exhibition slug exists; `place.kind` stays **`pavilion`**.

Golden campus that hosts many pavilion **spaces**: [`expo`](../expo/). Nest a rich interior with `copy: ./parts/<name>` when room grain is needed ([place recipe — CMS / multi-pavilion](../../../../packages/spec/doc/place/place-recipe.md#cms--multi-pavilion-catalogs-world-expo)).
