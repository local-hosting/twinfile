# Physical retail store

Vendor-neutral **place** (`twinfile/place/physical-store:0.1.0`) on `base-indoor-stack`: Z1–Z5 spine (arrival through service desk), staff **stations**, ordered **visits**, queue spine route, and in-store fixtures without DTPR or carrier branding.

Derived examples:

- [`wireless-mobile`](../wireless-mobile/) — mobile carrier retail + DTPR on kiosk, queue, pay, sensors, and greeter AI
- Private cable-retail overlay (osc-twinfile) — venue labels and venue crosswalk refs on top of this base
