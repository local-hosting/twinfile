# Twinfile documentation

Twinfile is an open format for a place you can check, build, and publish. One **`<unit>.twin.yaml`** names the stack (`from:`, `layers:`, `bindings/`); **`twin build`** builds a `Place` in memory. {{ className: 'lead' }}

1. **Pick a base** — geotype → archetype → `from: twinfile/base-*` ([examples](/examples)).
2. **Patch** — local `place/*.yaml` in merge order.
3. **Build** — `twin check`, `twin build`, run scenarios.
