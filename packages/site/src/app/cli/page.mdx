# twin CLI

`twin` ships with **`@local-hosting/twinfile-cli`** (`twin` / `twinfile` bins). It checks a unit, builds a `Place`, runs a scenario, and moves the unit to a registry. {{ className: 'lead' }}

Inside the monorepo, refs in `from:` and `with:` resolve automatically. Elsewhere, set `TF_TWINFILE_ROOT` or pass `--examples-root`.

## Everyday commands {{ anchor: false }}

| Command | What it does |
| --- | --- |
| `twin init place <dir> --geotype <slug>` | Writes a place with `from:` and `with:` mixins. `--no-from` and `--no-decorate` skip those steps. |
| `twin add plan <event> [dir]` | Binds an event to spaces tagged with `roles:`. |
| `twin add assets [dir]` | Adds a starter `assets` layer. |
| `twin check [dir]` | Validates manifest, layers, and contracts. `--strict`, `--frozen`, `--examples-root`. |
| `twin build [dir]` | builds a `Place` in memory and writes `<unit>.twin.lock` when lock write is enabled. |
| `twin layers [dir]` | Prints the merge stack (same layer chain as build). |
| `twin run [scenarioDir]` | Runs the scenario runner named by `use.runner`. |
| `twin verify [scenarioDir]` | Compares the run to a frozen digest. `--frozen`. |

From the monorepo root, after `yarn workspace @local-hosting/twinfile-cli build`:

```bash
yarn twin check path/to/unit
yarn twin build path/to/unit
```

## What a build records {{ anchor: false }}

**`twin build`** returns a **`Place`** in process memory (`Place.data`, `Place.meta`, `Place.digest`). Use **`TFPlace.load()`**, **`Place.toWire()`** (MCP **`twin://place`**), or the **`Place`** object directly. **`<unit>.twin.lock`** pins the manifest and layer chain when lock write is on.

**`twin pack`** writes an OCI layout to **`--out`** (or a temp directory); it is not stored under the unit tree by default.

## Publish {{ anchor: false }}

| Command | What it does |
| --- | --- |
| `twin pack [dir]` | Packages the OCI artifact. |
| `twin push [dir] --ref twinfile/name:tag` | Pushes to the registry. Set `GITHUB_TOKEN` or `OCI_REGISTRY_TOKEN`. |
| `twin pull <ref> --out <dir>` | Pulls a unit by ref. |
| `twin ref resolve`, `twin ref validate` | Resolves or checks a ref like `twinfile/shop:0.2.0`. |
