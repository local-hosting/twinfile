# @doppler-group/twinfile-spec

The spec is the source of truth: prose, JSON Schema (2020-12), and conformance vectors. It has no runtime. `@doppler-group/twinfile-core` pins a spec version and passes its vectors. {{ className: 'lead' }}

Current draft: `1.0.0-draft.1`. Manifest field: `twinfile: 1`. Source: [github.com/twinfile/spec](https://github.com/twinfile/spec).
